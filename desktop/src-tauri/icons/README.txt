Sendro app icons
================

The icons in this folder are GENERATED — do not hand-edit them here.

They are produced from the master brand assets in /branding by the
branding pipeline, which writes the following files into this folder:

  icon.ico          Windows executable / installer icon
  32x32.png
  128x128.png
  128x128@2x.png
  icon.png          master square PNG

tauri.conf.json (bundle.icon) references exactly these file names.
Run the branding pipeline before building the desktop bundle.
